## About This Lab

This repository documents my progress as I learn Git and GitHub.

### Learning Goals

- Understand version control
- Create and manage repositories
- Make commits
- Work with branches
- Learn push and pull

## Local Git Practice

This section was added locally using Visual Studio Code.

### Workflow

- Edit a file locally
- Check changes with git status
- Stage changes with git add
- Save a snapshot with git commit
- Send changes to GitHub with git push
